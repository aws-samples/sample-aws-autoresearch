# Vendored third-party template

`IEEEtran.cls` and `IEEEtran.bst` are the IEEE conference LaTeX class + BibTeX style by Michael Shell,
obtained from CTAN (`macros/latex/contrib/IEEEtran`). They are distributed under the **LaTeX Project
Public License (LPPL, v1.3)**, which permits redistribution, so they are vendored here rather than
downloaded at build time — the paper builds offline and deterministically.

- Upstream: https://ctan.org/pkg/ieeetran
- License: LPPL 1.3 (see the header of each file for the full terms)

`main.tex` and `refs.bib` in this directory are original scaffolds written for this project.
